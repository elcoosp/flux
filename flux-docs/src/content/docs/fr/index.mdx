Flux est un langage UI à écrire une fois pour iOS et Android natifs. Vous rédigez votre UI dans des fichiers `.flux`. En développement, une application hôte précompilée reçoit des patches binaires sur WebSocket et hot-reload votre UI en millisecondes. En release, la source exacte se compile en **SwiftUI** et **Jetpack Compose** idiomatiques. Pas de webview. Pas de pont JavaScript. Pas d'interpréteur en production.

| | Cross-platform traditionnel | Flux |
| --- | --- | --- |
| Cible de rendu | WebView / canvas | Vrai `UIView` / Compose `View` |
| Hot reload | Rebuild complet ou JS eval | Patch IR binaire sur WebSocket |
| Build release | Interpréteur livré en prod | Codegen SwiftUI / Compose |
| État | Verrouillé par framework | Graphe de signaux de style SolidJS sur un IR partagé |

La boucle de développement et l'artefact release viennent du **même Reactive Tree IR**. Vous itérez contre un hôte VM bytecode rapide pendant le développement et livrez du code natif par plateforme en release — pas de bifurcation, pas de « dev différent de prod ». Un harnais de parité (`flux-parity`) prouve continûment que l'exécution VM dev et le codegen release restent équivalents, donc les deux chemins sont vérifiés, pas supposés.

## Ce dont vous avez besoin

La chaîne d'outils Rust construit tout du côté CLI. Xcode (cible de déploiement iOS 16+) et le SDK Android sont requis uniquement pour les applications hôtes. Parcourez le [tutoriel de la première app](/tutorials/your-first-app/) pour l'installation complète.
