# FLUX-069: 1.0 beta hardening — dogfood + closed beta + bug bash (evidence)

- **Lane:** LANE-U (Phase 9 — 1.0 cut)
- **Depends on:** FLUX-036 (showcase apps), FLUX-068 (build/distribution), FLUX-062
  (DevTools on-device)
- **Source:** `CHANGELOG.md` §PRD-U deferred (the process gates needing real-app/human
  evidence)
- **Related ADRs:** ADR-0050

## Problem Statement

PRD-U froze the contracts but deferred the *evidence* gates: dogfood app (core team
ships one real app), closed beta (external teams, tracked time-to-diagnose/fix vs an
RN/Flutter cohort), full-stdlib bug bash. These "need human/real-app evidence and
cannot be completed in-repo." The roadmap §1 defines 1.0 as five evidence criteria,
not a feature checklist.

## Solution

Run the three evidence gates: (1) dogfood one real app on Flux; (2) closed beta with
external teams, tracking every DX friction point against the "10x" claim with actual
time-to-fix data; (3) full-stdlib + capability bug bash. Record the evidence against
the §1 criteria; only ship 1.0 when all five hold with evidence.

## Implementation Decisions

- This is a process/evidence issue — it orchestrates the other follow-ups; it files
  no *product* code itself but blocks the 1.0 tag.
- The **machine-enforced** half of the gate now lives in CI (within the LANE-U
  `docs/`/`.github/`/`scripts/` ownership): `.github/workflows/release-gate.yml`
  aggregates the existing component quality gates behind one `release-gate` status
  check, plus a blocking `contract-freeze` job
  (`scripts/release-gate/check-contract-freeze.sh`) that enforces the PRD-U wire +
  adapter version freeze across the Rust server and both native hosts
  (`docs/release/contract-versions.toml` is the frozen manifest). The optional
  `pin` tag freezes the gate to a 1.0-RC / 1.0 release.
- The **human-evidence** half (dogfood report, closed-beta time-to-diagnose/fix vs
  RN/Flutter, bug-bash log) remains a checklist in `docs/release/1.0-evidence.md`
  and gates the manual `v1.0.0` tag — it cannot be produced in-repo.
- Uses the FLUX-036 showcase apps as the dogfood/beta vehicles.

## Testing Decisions

- Evidence artifacts (dogfood report, beta time-to-fix data, bug-bash log) attached;
  the §1 five criteria checklist marked met with evidence.

## Out of Scope

- The contract freeze (PRD-U, done). Anything that lands code (those are FLUX-024..068).
