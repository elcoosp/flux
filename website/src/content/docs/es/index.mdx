## Cómo un tap se vuelve píxeles

<Steps>

1. **Dispatch** — un tap en `Button` evalúa su closure manejador en la VM del host,
   escribiendo una o más señales (p. ej. `count = count + 1`).

2. **Signals** — la VM reporta los ids de señales escritas, ordenadas
   ascendentemente (`signals`).

3. **Dirty set** — el host intersecta las señales escritas con `signal_deps` de
   cada nodo, emitiendo `dirty` en orden `(depth asc, id asc)`.

4. **Update** — solo los nodos sucios re-materializan sus props (≤ 2
   materializaciones, solo al cambiar) y disparan `update`. Los hermanos limpios
   no se tocan — `skip_unchanged`.

5. **step_end** — contadores acumulativos cierran el paso: `built`, `updated`,
   `skipped_unchanged`, `detached`, `prop_materializations`.

</Steps>
