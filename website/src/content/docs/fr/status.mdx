Cette page est le foyer du **badge de conformité généré par CI**. Un job CI rejoue
les scénarios golden de `reconcile-trace-format.md` contre les deux hôtes et émet
un badge ici confirmant que Swift ≡ Kotlin produit des traces octet-pour-octet
identiques.

<StatusBadge status="pending" detail="Parité de réconciliation Swift ≡ Kotlin (ADR-0027)" />

## Ce qui est vérifié

| Scénario | Assertion |
|---|---|
| `counter_1000` | arbre de 1 000 nœuds, un `Text` lit le signal 1 → `dirty` = exactement ce Text ; 1 update, 0 build |
| `noop_dispatch` | le handler écrit le signal 99, rien ne le lit → `dirty: []`, tous les deltas à zéro |
| `pure_subtree` | sous-arbre `@pure` ; signal frère écrit → zéro événement dans le sous-arbre |
| `cond_flip` | la condition `If` bascule → build+detach = nb d'enfants de branche ; exactement 1 `setchildren` ; mount/cleanup une fois chacun |
| `unrelated_signal` | signal écrit, absent des deps d'un nœud → zéro update/build/detach |

La règle générale (de `reconcile-counters-and-budgets.md`) : **tous les compteurs
après un dispatch sont bornés par `|dependents[S]|` + la taille du diff structurel —
jamais par la taille de l'arbre.**

## État actuel
