## What is being checked

| Scenario | Assertion |
|---|---|
| `counter_1000` | 1,000-node tree, one `Text` reads signal 1 → `dirty` = exactly that Text; 1 update, 0 builds |
| `noop_dispatch` | handler writes signal 99, nothing reads it → `dirty: []`, all deltas zero |
| `pure_subtree` | `@pure` subtree; sibling signal written → zero events inside the subtree |
| `cond_flip` | `If` condition flips → build+detach = branch child counts; exactly 1 `setchildren`; mount/cleanup once each |
| `unrelated_signal` | signal written, in no node's deps → zero update/build/detach |

The general rule (from `reconcile-counters-and-budgets.md`): **all counters after
a dispatch are bounded by `|dependents[S]|` + structural-diff size — never by tree
size.**
